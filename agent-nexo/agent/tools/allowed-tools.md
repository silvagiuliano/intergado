# Ferramentas previstas para o protótipo

## Disponíveis na simulação

- `create_or_update_case`: criar ou atualizar um caso fictício em memória/arquivo de teste.
- `attach_evidence_reference`: associar mensagem simulada, remetente, horário e nome do anexo.
- `set_case_status`: mudar apenas os estados do caso de teste, mantendo histórico antes/depois.
- `ask_clarification`: formular pergunta curta no canal simulado.
- `request_human_review`: colocar uma versão do caso em revisão.

## Fora do escopo do protótipo

- Enviar mensagens reais pelo WhatsApp.
- Capturar grupos ou mensagens privadas.
- Atualizar planilhas, dashboard, Realtec, AgroHUB ou banco.
- Autorizar compra ou pagamento, executar pagamento, baixa ou conciliação.
- Consultar fornecedores automaticamente.

As ferramentas acima são contratos conceituais para a demonstração, não funções implementadas. Ao iniciar um teste com mensagens reais, limitar a um grupo de teste previamente autorizado e usar apenas dados de teste.
